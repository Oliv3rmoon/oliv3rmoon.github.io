# Orbit / Study 001

Original conceptual sculpture created in Blender 5.2.1 for Andrew Sandoval's portfolio.

- `blender/orbit-study.blend`: editable native scene, sculpture, studio lighting and camera.
- `blender/create_studies.py`: procedural scene generator and GLB/render export.
- `renders/`: full-resolution studio renders.
- The web sculpture is exported to `public/models/orbit-study.glb`.
- The web posters are WebP versions of the renders.

This sculpture is a visual exploration for the portfolio. It is not the animatronic dinosaur's design, CAD model, or a fabricated prototype. The dinosaur is currently in brainstorming, 3D model mapping, and CAD planning.

The DPOC screenshot depicts its public homepage in September 2026. The previously approved AI-styled portrait is retained unchanged.
